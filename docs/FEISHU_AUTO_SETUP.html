🎯 有医帮飞书接入 - 5分钟完成指南

第1步：打开飞书开放平台

点击下方链接或手动访问：

🔗 打开飞书开放平台

（如果已登录，会直接进入开发者后台）

第2步：创建应用

在页面右上角找到「开发者后台」→「应用管理」→「创建应用」

填写以下信息：

  • 应用类型： 机器人
  • 应用名称： 有医帮健康助手
  • 应用描述： 互联网医疗服务平台AI助手

点击「创建」按钮

第3步：获取配置信息

创建成功后，在应用详情页：

  1. 复制「App ID」→ 粘贴到 youyibang-web/config/feishu-config.json 的 app_id 字段
  2. 点击「App Secret」→ 「显示」→ 复制 → 粘贴到 app_secret 字段
  3. 在「事件订阅」→ 复制「Verification Token」→ 粘贴到 verification_token 字段
  4. 在「事件订阅」→ 复制「Encrypt Key」→ 粘贴到 encrypt_key 字段

第4步：配置机器人

左侧菜单 → 「机器人」→ 「添加机器人」

  • 机器人名称：有医帮健康助手
  • 机器人描述：AI健康咨询助手
  • 点击「添加」
  • 复制生成的「Webhook URL」→ 粘贴到 bot_webhook 字段

第5步：配置事件订阅

左侧菜单 → 「事件订阅」→ 「启用」

  • 请求URL：https://your-domain.com/api/feishu/webhook
  • 加密方式：明文模式
  • 点击「保存」

第6步：测试

将机器人添加到测试群组，发送消息测试：

  • 「健康」→ 返回健康服务介绍
  • 「食疗」→ 返回中医食疗建议
  • 「帮助」→ 显示功能菜单

✅ 全部完成！
